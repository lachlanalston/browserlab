This is a fake Microsoft login page. No data was captured. Here's what to check:

  • URL: This page is at browserlab.au/phishing/ — not login.microsoft.com
  • Padlock: Real M365 login uses HTTPS at a Microsoft domain
  • Unsolicited link: Phishing links arrive via email or QR code
  • Urgency: Phishing emails pressure you to act fast
  • Hover before clicking: Hover links to preview the real URL
