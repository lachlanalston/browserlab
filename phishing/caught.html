Red flags on that page

  • Wrong URL — page was at browserlab.au/phishing/, not login.microsoft.com
  • Unsolicited — you received a link out of nowhere via email, SMS, or QR code
  • Urgency — phishing messages say "act now", "account suspended", "verify immediately"
  • Lookalike domain — attackers use micros0ft.com, login-microsoft.com, microsoft-login.xyz

What to do if you clicked a real phishing link

  • Do not enter any credentials — close the tab immediately
  • If you entered credentials, change that password right now from a known-safe device
  • Enable MFA on the account if not already enabled
  • Report to your IT team — they may need to check login logs
  • Run a malware scan if you clicked a download link
