That was a tech support scam.

If this were real, you would have called a scammer — not Microsoft. They would have charged you hundreds of dollars to "remove" viruses that were never there. This is a training demo.

The golden rule: Microsoft, Windows, Apple, and your antivirus will NEVER display a phone number in a browser alert and ask you to call them. Ever. No exceptions. If you see a phone number in a browser popup, it belongs to a scammer.

Red flags on that page

  • Phone number in browser — Microsoft has no mechanism to do this; only scammers do
  • Browser claimed to scan your PC — browsers cannot scan your filesystem for viruses
  • "Do not close this window" — manufactured urgency to prevent rational thinking
  • Blocked right-click and keyboard shortcuts — designed to make you feel trapped
  • Fake error code — 0x80073b01 is a real Windows error; scammers use real-looking codes to appear credible
  • Blinking alerts and animations — visual stress tactics, not real diagnostics

What happens if you call the number

  • Scammer asks you to install remote access software (AnyDesk, TeamViewer, UltraViewer)
  • They "show" you fake virus infections inside Event Viewer or CMD to build panic
  • They demand $150–$500 for "Microsoft certified removal"
  • They may install actual malware, steal banking credentials, or set up persistent access

What to do if this happens on a real device

  • Close the browser tab — if it won't close, press Alt+F4 (Windows) or Cmd+Q (Mac)
  • If the page is in fullscreen, press F11 or Escape first
  • Do NOT call the number — hang up immediately if you already did
  • If you installed remote access software, disconnect from the internet and contact your IT team now
  • Run a real scan using Windows Security (the built-in app — search "Windows Security" in Start)
